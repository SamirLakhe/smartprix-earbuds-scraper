Specifications and prices of TWS (true wireless) earbuds listed on Smartprix.

Collection: scraped in November 2026 with Selenium (to load the dynamic listing page) and parsed with BeautifulSoup.
Source: smartprix.com
Scraper code: https://github.com/SamirLakhe/smartprix-earbuds-scraper
Cleaning notebook: https://www.kaggle.com/datasets/samirlakhe/smartprix-tws-earbuds-dataset

Files:
- earbuds.csv: raw data as scraped
- earbuds_cleaned.csv: cleaned version
